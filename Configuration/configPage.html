"Because you watched …" home rows

Personalised recommendation rows built from titles you recently watched, served from GET /BetterRecs/Recommendations?userId=<id>. Each row reuses the scoring engine configured above.

To show these on the home screen, install the Home Screen Sections (HSS) plugin. BetterRecs registers a single blended row with HSS at startup, combining matches from several recently-watched titles under the heading set below. (The per-title "Number of rows" setting only applies to the raw API endpoint, which front-ends like KefinTweaks can also consume.)

When off, the recommendations endpoint returns nothing and no row is registered with HSS.
